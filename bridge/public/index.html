Выполнение команд

Опасно: команды выполняются от твоего имени в рабочей папке. Включай, только если понимаешь риск. Все вызовы пишутся в audit.log.
Этот же флаг открывает изменяющие команды git (commit, checkout, push) и фоновые процессы start_process / kill_process. Читающие git-команды (status, diff, log) доступны всегда.

Сетевой доступ

По умолчанию выключено. С включённым флагом модель может скачивать файлы в рабочую папку и отправлять запросы наружу — в том числе отправить содержимое твоих файлов на чужой сервер.

Дополнительные папки

Проекты вне рабочей папки, с которыми модели разрешено работать. По одному пути на строку. Пустой список — доступ только внутри рабочей папки.
Это расширяет доступ модели за пределы рабочей папки — включая запись и удаление. Добавляй только те проекты, которые реально нужно править.
